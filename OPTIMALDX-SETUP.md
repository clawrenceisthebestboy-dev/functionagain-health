## How to Use It (Workflow)

**Step 1 — Get client labs**
- Client orders through Ulta Lab Tests (Sara's affiliate link) OR
- Client brings existing lab results (PDF or paper)

**Step 2 — Enter lab values**
- Optimal DX has a PDF parser (upload the lab PDF, it extracts values automatically)
- Or manual entry for each marker

**Step 3 — Run analysis**
- Platform compares against functional optimal ranges
- Flags values outside optimal window
- Identifies patterns (e.g., "early thyroid sluggishness," "insulin resistance pattern," "iron deficiency without anemia")

**Step 4 — Generate report**
- Professional PDF report with findings, explanations, and recommendations
- Branded with Sara's business name
- Client receives a clear, actionable document

**Step 5 — Review session**
- Sara walks client through the report
- Recommends targeted supplements, lifestyle changes, follow-up labs
- Refers to appropriate specialists when needed
